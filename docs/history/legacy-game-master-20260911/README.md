## 在本对话开始

可以直接说：

> 开始制作。今天主题是……，参加的孩子是……。我们一起做……。第一轮先问……。

也可以只说主题；AI 会先整理已经明确的信息，只补问会影响下一步的必要项。孩子可以说中文或英文，也可以由老师代记。无需填写模板或学习口令。

本次语音课堂已结束，记录依据实际收到的转写。游戏已完成制作并有儿童试玩反馈；独立收音与说话人识别系统尚未接入。
