01 · 分轨调音 / Mixer

M：只静音该轨；S：只听已选轨道。人声和环境各自保留，八种动物可以独立叠加。停止播放会回收所有声源。

02 · 演奏与时间编排 / Arrangement

点击轨道上的声音块可编辑。电脑数字键 1–8 或屏幕按钮触发音效；不会改变原始录音。声音超出本幕时会阻止加入，而不是截掉尾音。

硬件 MIDI 为可选：需支持 Web MIDI 的浏览器并由你授权。Note-on 对应采样，CC7 调音量，CC10 调声像；不支持时照常用屏幕和键盘。MIDI 是控制事件，不是音频。

03 · 保存、导出与数字人接口 / Export

本机保存不等于提交老师。WAV 在浏览器本地渲染，带峰值保护；JSON/MIDI 只保存编排控制，声音素材仍需单独保管。口型包络是音量驱动的初步接口，不是音素级口型或完整数字人生成。

本人配音入口 / Record your performance

先演一遍开心、害怕或坚定的台词。试听满意后，将录音交给固定版本的本地克隆生成器。生成器源码随技术栈留存，此网页不会调用云端克隆。

浏览器会另行询问麦克风权限。停止录音或离开页面会关闭麦克风；保存格式取决于浏览器支持。
