## Classroom use

1. Enter the HUB, open the game, try the existing world. The new play entry has a left toolbar with HUB, report, language and pause controls.
2. Open Write report and choose your own first name. Record the device and places actually tested; give four ratings; explain a favourite moment; describe a reproducible problem or explicitly say none/not sure; propose one new feature and explain why.
3. Export TXT and JSON, or deliberately share the report file with the teacher. The teacher can import collected JSON files through the report page's teacher section. Validate the student name after importing.

Local save/export is NOT teacher receipt. Different iPads do NOT automatically synchronize. Use one browser on each device; export before clearing browser data, changing devices or switching between online/offline. Storage failure shows an error and still permits emergency draft export. A sharing dialog is not delivery confirmation.

Reports are separated by project, class date, reviewed game commit and selected student. No student is preselected. Test reports were not published. Public pages contain first names and deidentified discussion summaries only, not recordings or raw classroom transcripts.
