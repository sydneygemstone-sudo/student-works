# Student HUB tasks — mandatory canonical entry

For creating, packaging, reviewing or modifying a student HUB (教务/HUB/学生作品/家长展示):
- Read `HUB-ENTRY.json`, then `docs/hub-standard/LOCK.json`, then `docs/hub-standard/HUB-STANDARD.md` before implementing.
- Required standard: **CLASSROOM-HUB-R5-20260923 / 3.0.0 / APPROVED_LOCKED**.
- Run `python3 scripts/verify_hub_standard.py` first. Mismatch means STOP, not fallback to Naomi, original Alex/Victory, r1–r4, a latest filename or old session folder.
- Preserve the approved r5 example directory; implement new lessons/candidates separately. Recompute lesson data; never copy the sample 86%, costs, people or decisions as facts.
- A new standard version or change to the golden baseline requires Dean's explicit approval. This file does not grant publishing or deletion permission.

The full contract and handoff prompt exist only in the canonical standard. For non-HUB work this document adds no workflow requirement; retain applicable project-specific instructions.
