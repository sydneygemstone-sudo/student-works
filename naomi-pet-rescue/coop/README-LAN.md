# Naomi《小动物回家》双 iPad 局域网联机探索版

## 1. 简介与核心定义

本版本是为 Naomi 和 Dean 定制开发的局域网双机协作探索模式：
- **第三人称越肩探索**：每位玩家拥有独立的跟随视角，从角色（小熊/小兔）后上方观察前方道路，墙体与树篱真实遮挡视线。
- **各自独立控制**：第一台 iPad 控制小熊（2步/抱2只），第二台 iPad 控制小兔（3步/抱1只）。
- **共同回合制**：共享救援世界、动物、家园、勇气、庇护与天气。双方各自完成本轮行动并点击“结束本回合”，两端均就绪后服务器原子结算推进下一回合。
- **Naomi 创意实现**：
  1. **石头退路箭头提示**：撞上石头或死胡同树篱时不扣行动点，显示清晰箭头提醒退路与转向；
  2. **树篱小迷宫**：花园东北侧设有带入口花廊、核心花亭（待救小兔宝宝）、出口拱门及 2 个浅死胡同的立体小迷宫。

---

## 2. 快速安装与启动步骤

请在作为局域网主机的 Mac 终端中执行：

```bash
# 1. 进入联机版目录
cd "student-works/naomi-pet-rescue/coop"

# 2. 安装依赖（生成/校验 package-lock.json）
npm install

# 3. 运行完整自动化测试套件（单元测试、网络协议测试、全流程模拟测试）
npm test

# 4. 构建与本地资源准备（将 Three.js 提取到本地 vendor，保证无外网纯离线可用）
npm run build

# 5. 启动局域网联机服务
npm run start:lan
```

## 3. 设备连接与入房指南

### 3.1 局域网地址检测
服务启动后，控制台会自动列出检测到的真实局域网 IPv4 地址。例如：
- **Mac 本机调试入口**：`http://localhost:8787/naomi-pet-rescue/coop/`
- **iPad Safari 入口**：`http://192.168.1.103:8787/naomi-pet-rescue/coop/`（以终端实际打印的 IP 为准）
- **健康检查接口**：`http://localhost:8787/health`

### 3.2 双机联机流程
1. **第一台 iPad (小熊)**：
   - 打开 Safari 访问 `http://<Mac-IP>:8787/naomi-pet-rescue/coop/`；
   - 点击“小熊”卡片，输入名字（默认“小熊”），点击 **“立即创建房间 🚀”**；
   - 屏幕上显示生成的 4 位大写房间码（如 `2DMS`），并可一键复制加入链接。
2. **第二台 iPad (小兔 Naomi)**：
   - 方式 A：Safari 访问第一台 iPad 分享的链接（自动带 `?room=XXXX` 参数）；
   - 方式 B：访问同一网址，在“加入已有房间”标签页输入 4 位房间码，角色自动分配小兔 Naomi，点击 **“加入该房间 🎮”**。
3. **开始探索**：
   - 两人均就绪后进入故事剧场，观看或跳过原版 IndexTTS 2.5 旁白与精美插画，共同出发！

## 4. 停止与端口排查

- **正常停止**：在终端按 `Ctrl + C` 即可优雅停止服务。
- **自定义端口**：如需更换端口，可通过环境变量指定：
  ```bash
  PORT=8888 npm run start:lan
  ```
- **排查占用端口**：
  ```bash
  lsof -i :8787
  ```

## 5. 常见网络与 iPad 适配排查

1. **iPad 无法打开页面**：
   - 请确认 Mac 与两台 iPad 连接在**同一个 Wi-Fi 路由器**或手机热点下；
   - 检查路由器是否开启了“AP 隔离 / 访客网络隔离”（Guest Isolation）。如开启，设备间无法通过局域网直接通信，请连接普通主 Wi-Fi；
   - 检查 macOS 系统设置 -> 网络 -> 防火墙，确保允许 Node.js 接收传入连接。
2. **Mac 睡眠导致连接中断**：
   - 若 Mac 合盖或进入睡眠，局域网连接会挂起；可在“系统设置 -> 节能”中设置为合盖不休眠或使用充电器。
   - 服务具备**断线重连恢复机制**：任一玩家短暂息屏或刷新后，凭本地恢复令牌会自动回到原角色，房间旧就绪状态安全清除，无需重启房间。
3. **iPad 横屏操作防滚动**：
   - 页面已适配 iPad Safari 安全区，采用标准至少 48×48px 大触控按键与 `touch-action: manipulation`，防止误触页面滚动或缩放。
