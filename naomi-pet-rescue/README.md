[直接在线玩](https://sydneygemstone-sudo.github.io/student-works/naomi-pet-rescue/)

两个人在同一台电脑上轮流操作，合作把8只小动物在暴风雨之前送回家。无需登录或安装；也可以下载本目录，双击 `index.html` 离线玩。玩家名字可在开始界面修改。

## 怎么玩

1. 小熊每回合走2步、能抱2只；小兔每回合走3步、能抱1只。
2. 点亮起的相邻格子移动，也能用方向键。遇见动物自动抱起，回到中间小屋自动送回。
3. 靠近队友时可以递动物；一起分头救援、接力送回。
4. 走完步数自动换人，也可以主动结束回合。每结束一回合雨云靠近一步，每4回合打一次雷。
5. 在28回合用完前把8只全部救回，两个人一起赢。

## 9月8日升级与试玩修复

- **绘本花园**：有全身造型和表情的小动物；倒计时、步数和行动放在棋盘旁。
- **石头与森林**：石头要绕开，普通森林花2步进入。
- **看得见的绳网**：最多两处网开局就标在空森林里，不会突然落到谁身上。可以绕开；无庇护时花3步进入并拆网，拆掉后就是普通森林，不会继续缠住角色。每张地图都保留不穿过绳网的救援路线。
- **勇气自动加步**：救回每只动物或开出勇气礼盒获得2勇气。有2勇气就自动为当前队员加2步，每回合一次，不用找按钮。剩余勇气全部保留到后面；数字显示真实余量，不会因为圆点满了而丢失。
- **神秘礼盒**：可能带来勇气，也可能是恶作剧炸弹，让打开者下次暂停一回合；小动物不会受伤。
- **家园守护**：在家花1步获得1层庇护，每回合一次，最多2层。庇护能挡一次雷雨；穿过有网的森林时也可消耗1层盾，只花普通森林的2步就把网拆掉。

这次修复来自课堂试玩反馈：周期绳网总落到小熊、勇气满格却没有明显作用。危险现在能够预判，奖励自动生效。

## 验证记录

- 20项规则测试通过，包括满格奖励保留、熊兔自动加步、绳网消耗及清除、炸弹暂停恢复、交接与胜负。
- 200个随机种子检查动物和礼物均有不经过绳网的可达路线。
- 修复后在浏览器通过正常按钮点击完成一局：8只全部救回，暴风雨还剩5回合。没有调用自动通关函数或胜利钩子。
- 另一次浏览器定向检查确认两位队员送回动物后立即增加步数，拆网后网从格子消失且不残留在角色上。
- 这些是规则和浏览器验证；更多儿童试玩、手机和平板手感仍需继续测试。

## 调整规则

基础数值在 `game-core.js` 的 `CONFIG` 中：`STORM_STEPS` 为倒计时回合数，`PETS` 为动物数，`ROCKS` / `FORESTS` / `NETS` 为地形和最多绳网数量，`BEAR` / `BUNNY` 为两个角色的步数与容量。

`?seed=12` 可以固定地图复现问题。仅供开发的 `?auto=...`、`?end=win` 和 `?end=lose` 钩子不代表真实试玩通过。
