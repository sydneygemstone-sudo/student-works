# 🐻🐰 小动物回家 —— Naomi 的合作桌游

- 玩法：两个人在同一台电脑上轮流操作，**合作闯关**（一起赢或一起输）
- 主题：小动物 / 宠物
- 时长：约 10 分钟一局
- 打开方式：双击 `index.html`（无需联网，纯本地）

## 怎么玩（30 秒版）
1. 🐻 小熊一回合走 2 步、能抱 2 只；🐰 小兔一回合走 3 步、只能抱 1 只。
2. 点亮起来的格子就能走（也可用键盘方向键）。走到小动物那里自动抱起，走回 🏠 家自动放下。
3. 挨着队友时可以「🤝 递给队友」。
4. 每走完一手，🌧️ 暴风雨就近一步；每 4 手会打雷，一只小动物受惊跑走一格。
5. 暴风雨到达（28 手）之前把全部 8 只送回家 → 一起赢。

## 调难度 / 调时长
所有数字都在 `game-core.js` 顶部的 `CONFIG`：

| 常量 | 初值 | 作用 |
|---|---|---|
| `STORM_STEPS` | 28 | 暴风雨到达的总手数，**主要控制时长和难度**（调小更难更短） |
| `PETS` | 8 | 走丢的小动物数量（每 +2 只约 +5 手） |
| `GRID` | 7 | 棋盘边长（奇数） |
| `SCARE_EVERY` | 4 | 每几手打一次雷 |
| `BEAR` / `BUNNY` | 2步/2只、3步/1只 | 两个角色的能力 |

校准数据（`node -e 'console.log(require("./game-core.js").simulate(2000,{},7))'`）：
启发式策略 2000 局，中位 22 手（P25–P75：19–24），`STORM_STEPS=28` 时胜率约 96%；小孩玩得没那么高效，预期 24–28 手，每手 20–25 秒 ≈ 10 分钟。
