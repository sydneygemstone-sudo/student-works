# Michael · three-model comparison / 三模型对比

## Frozen-source engineering review / 冻结源码工程初评
| Version | Score | Interpretation |
|---|---:|---|
| GLM | **54 / 100** | Core loop works, but random route generation and lighter delivery/test evidence reduce reproducibility. |
| Claude | **84 / 100** | Richer authored course, moving/rotating obstacles and jump forgiveness; original delivery is mainly keyboard-oriented. |
| Codex Astra | **91 / 100** | Deterministic course, touch controls, pause and stronger source/release structure; frozen original issues remain counted. |

These scores review the delivered source against this lesson's brief. They are **not** rankings of the models' overall intelligence and are not Michael's fun scores.
这些分数只评价本课冻结源码，不是模型综合智能排名，也不是 Michael 的主观好玩评分。

For GLM and Claude, iPad touch buttons are a later viewing adapter and are not counted in the original score. Codex Astra already contains native touch controls.
