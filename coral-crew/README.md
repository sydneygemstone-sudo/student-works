# 珊瑚船员 · Coral Crew (局域网 3D 多人合作升级版)

Quentin 与 Lisha 共同创作的双人 3D 海洋合作游戏。海盗守船备粮开重炮，潜水员深海寻宝避险，并集成全套课堂 Game Master 教师控场协议与局域网自动联机功能。

## 🌟 核心特色与新玩法升级

1. **局域网自动组网 (LAN Multiplayer)**：
   - 服务端自动检测本机局域网 IP (`http://192.168.1.x:18888`)，大厅及教师端内置**动态 SVG 二维码**。
   - iPad 相机直接扫码即可秒进游戏，两台 iPad 输入同一房间号（如 `CORAL`）即可联机。
2. **海盗 (Pirate - Leesha)**：
   - 🍉 **切西瓜与榨特饮**：三刀切瓜提供食物；支持榨取“西瓜能量特饮 (Smoothie)”，潜水员回船畅饮获得极速涡轮加速！
   - 💥 **双联重炮与西瓜诱饵**：开炮轰击撞船怪或巨妖触手；投掷西瓜诱饵吸引并引开鲨鱼。
   - 🔨 **修补船体与绞盘救援**：修复受损船身，危急时刻拉紧卷扬机缆绳救援潜水员。
3. **潜水员 (Diver - Quinton)**：
   - 🤿 **水下氧气系统**：潜水消耗氧气，回船或浮出水面瞬间补满。
   - 📡 **脉冲声纳扫描**：发射声纳扫描全海域，高亮透视隐藏宝藏与危险鲨鱼。
   - 🦪 **珍珠蚌与沉船宝箱**：水下有时机开合的贝壳蚌（采出发光黑珍珠）和古代沉船秘宝箱。
   - 🫧 **西瓜气泡水枪**：击退追击的鲨鱼群，攻击巨妖弱点吸盘。
4. **北海巨妖 (Kraken Boss)**：
   - 巨妖挥舞触手袭击小船！海盗轰触手，潜水员打吸盘弱点，合力击退掉落大量金币与宝藏！
5. **团队金币与黄金工坊 (Gold Shop)**：
   - 采珍珠、交宝藏、捕鱼、答题均可赚取共享团队金币。
   - 随时在工坊升级：超级大炮（伤害翻倍）、加速脚蹼（游速+25%）、装甲船身（生命+20）、黄金切瓜刀。
6. **Game Master 教师控场中枢 (`/teacher.html`)**：
   - 老师控制回合与出题，一键广播推送到学生 iPad 屏幕，支持浏览器 TTS 自动朗读。
   - 孩子在游戏内随时点击【💡 创意想法】提交灵感，老师后台分检归属并一键采纳实装（奖励金币、召唤巨妖、改变天气）。
   - 实时监控全局两台设备、船体、氧气、金币、宝藏。
7. **纯本地合成 Web Audio 音效**：
   - 海浪声、切瓜音、双音阶金币铃声、大炮轰鸣、声纳嘟嘟声、胜利号角。

## 本地与局域网运行

需要 Node.js (支持 ES modules 的 LTS 版本)。

```bash
# 1. 安装依赖
npm install

# 2. 运行单元与集成测试 (9 项测试全部通过)
npm test

# 3. 启动局域网服务 (默认端口 18888)
npm start
```

启动后终端会打印出本地与局域网访问地址：
- **电脑端游玩**: `http://localhost:18888/`
- **局域网 iPad / 手机**: `http://192.168.1.108:18888/`
- **教师主控台**: `http://192.168.1.108:18888/teacher.html`（默认口令：`CORAL`）
- **二维码端点**: `http://192.168.1.108:18888/api/qr`

## 游戏规则与目标

- 海盗切瓜备粮、开炮御敌；潜水员水下寻宝带回船下金圈交付。
- 背包暂存，交回船边才计入 **5 颗宝石 + 2 颗星星** 的最终通关目标。
- 零饥饿或零氧气时将受限，可回船补给或使用救援西瓜恢复。
