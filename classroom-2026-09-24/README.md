# 2026-09-24 Classroom Recovery / 课堂回收

Entry: index.html. Martin and trio each have HUB, comparison, development, costs, guide, learning/parents and feedback pages, in English and Simplified Chinese.

Source of truth: lesson-data.json + records/recovery-manifest.json + records/usage.json. The Markdown lesson records carry the full requirements and learning reconstruction. Every non-verbatim account is labelled; no missing student outcome is invented.

R5 base styles are copied byte-for-byte from the locked 23 September standard. app.js is a course-specific, data-driven renderer; the protected golden artifacts are not changed. The seven-stage gates describe the game projects, not a claim that all versions pass the complete R5 runtime requirements.

New server-dependent branches are preserved as candidates, not silently converted into solo games or claimed to run on Pages. The UI exposes source/runtime downloads and screenshots. Existing solo builds remain separate.

Reports are local drafts per reviewer and are not automatically sent. No audio or raw chats are public. Detailed visible execution messages and original host metadata are in the existing private academic-affairs-archive repository.
