# Leo vs Nathan · AI 一次成型的格斗游戏

在线玩：https://sydneygemstone-sudo.github.io/student-works/leo-vs-nathan/ · 本作品收录于学员作品仓库，只写学生名字。

> 课堂示例:一句话给 AI 下单 → 收到一个完整能玩的游戏。第 4/5 章「下单 → 监工 → 终审」环节的实物案例。

## 这是什么

一个双人同屏格斗小游戏,**单文件 HTML,零依赖,离线可玩**。由 Claude(Fable 5)在一次会话里根据一句话需求整体生成(2026-08-15),之后仅做过一处小修(窗口失焦时清空按键状态)。JS 部分通过 `node --check` 语法校验。

**原始下单指令(一字未改,含错别字):**

```
make a fihgting game，2 characters， Leo and nathan
```

就这一句——拼错了 "fighting",标点混用中英文——AI 交付了带血条、计时器、KO 判定、人机模式、命中特效的完整游戏。

## 怎么打开

双击 `index.html` 即可(或任意静态服务器)。不需要联网、不需要安装任何东西。

> ⚠️ **课堂提示:游戏需要实体键盘**,iPad Safari 上打不了。投影演示请用老师电脑跑;单人演示选「挑战电脑 Nathan」模式即可一个人玩。

## 玩法

- 两种模式:**双人对战**(同一键盘)/ **挑战电脑 Nathan**(开始画面上切换)
- 每局 60 秒,血量清零即 KO;时间到则血多者胜。KO 后按 **R** 或点击画面再战

| | Leo(左,金色) | Nathan(右,青色) |
|---|---|---|
| 移动 | A / D | ← / → |
| 跳跃 | W | ↑ |
| 快拳 | F | K |
| 重踢 | G | L |

快拳快而轻,重踢慢而重、带击退浮空。

## 课堂怎么用(建议)

1. **展示下单指令**(上面那句),让孩子读一遍,找出里面的错别字。
2. **当场打开游戏玩一局**——引出讨论:AI 看懂了错别字,为什么?(看例子找规律,不是逐字死抠。)
3. **反转提问**:错别字它都懂,那是不是随便说说就行?→ 不是。指令越清楚,交付越接近你想要的。可以现场追问孩子:"如果你想要三个角色/想让 Leo 会放火球,该怎么给 AI 说清楚?"
4. **终审权环节**:让孩子当验收官,玩几局挑毛病(哪里不公平?哪里像 bug?)——「我发现它错了」必填。
5. 进阶(第 5 章):把孩子提的改进意见整理成新的下单指令,课后真的发给 AI 改一版,下节课对比交付。

## 技术档案

- 形态:单文件 `index.html`(Canvas 2D,约 18 KB),无外部资源、无 CDN、无构建步骤
- 内容:物理(重力/跳跃/击退)、攻击判定(前摇/判定帧/后摇)、硬直、命中定帧、屏幕震动、粒子特效、简单 AI、胜场记录
- 在线可玩副本(Claude Artifact,与本文件同源):https://claude.ai/code/artifact/03110467-a523-4d62-8ad6-8c59a5b0c8b9
- 尊重系统「减少动态效果」设置(自动关闭震动/减少粒子)
